# I001-F02 引用内容契约（HTML 接管增量）

> 范围：HTML 接管开启后，进入会话输入框的引用文本、来源路径与本 Feature 对 F01 内容
> 契约的增量与沿用边界。实现契约见 [implementation.md](implementation.md)；测试与验收见
> [testing-and-acceptance.md](testing-and-acceptance.md)。
> **本文档不复制模板**：原文块、指针块、截断、路径相对化、敏感名单、`summary` 契约与
> 已引用记录的权威定义仍是 F01 的
> [quote-content-contract.md](../../feat-i001-f01-text-preview-quote/core/quote-content-contract.md)。
> 两者冲突时以 F01 为准，本文档只追加 HTML 特有的条款。

## 1. HTML 摘录的来源与保真口径（本 Feature 新增的唯一内容条款）

### 1.1 来源

摘录文本来自接管 iframe 内的选区，语义等价于浏览器对 `Selection.toString()` 的结果：
块级元素之间产生换行，行内空白按渲染规则合并。

### 1.2 保真对象是渲染文本

- 保留：空行、块级换行、行与行之间的结构。
- 不保留：源码缩进、制表符、行内多余空白、注释、标签本身。
- 不重排、不 trim 单行、不加代码围栏——这三条与 F01 §1 一致。
- **不得**为了"看起来像源码"而重新缩进、补空格或插入围栏。

即：同一段内容，从 HTML 源码里「摘录保真」是不可达的；可判定的准绳是**浏览器渲染
结果**。断言方式为：把插入后的消息文本去掉行首 `> ` 前缀，与页面上实际可见、被选中的
文本逐字比对。

### 1.3 与 F01 §1 一致的部分

- 整段首尾各去掉一个空行。
- 行尾统一归一为 `\n`。
- 摘录为空或仅空白时不插入。
- `来源：` 与摘录之间恰好一个空行；`来源：` 是固定中文标签，不随界面语言变化。

## 2. 模板

原文块与指针块模板**完全沿用** F01：

- 原文块：`<摘录>\n\n来源：<来源路径>`（见 F01 §1）。
- 指针块：`已引用过：<来源路径>\n原文未重复贴出；需要时请重新读取该文件。`（见 F01 §2）。

一次插入只会是其中一种形态；两者互斥。HTML 不引入第三种形态。

## 3. 来源路径

- 路径来源：`sidebar.right.tab.document.actions` 位点 owner props 提供的 `absolutePath`。
- 形式与算法：完全沿用 F01 §5（工作区内为工作区相对路径、`/` 分隔、Windows 反斜杠
  归一、工作区外保留原样、相对化失败不阻断不通知）。
- HTML 特有约束：不写行号、不写选择器、不写锚点；接管与否不改变路径写法。

## 4. 截断

- 阈值、算法、截断说明文案：完全沿用 F01 §4（200 行 / 8000 字符，先到先截）。
- 行数按**渲染文本**的行切分（块级换行即行边界）。
- 桥的 65536 字符传输上限不改变可观察输出：内容契约最多保留 8000 字符，二者不冲突，
  实现不得据此另设截断提示。

## 5. 指针降级

完全沿用 F01 §2 与 §8：同一会话内同一路径自第二次引用起插入指针块，键用插入时写入
`text` 的那个路径字符串。HTML 文件与文本文件共用同一记录空间，不按格式分区。

## 6. 敏感名警示

- 规则完全沿用 F01 §6：只看文件名，命中不阻断，插入成功后恰好一条 `info`。
- HTML 文件名同样参与匹配（例如 `notes/secret.html`、`deploy-credentials.html`）。
- 命中且插入失败时只发失败的那条 `error`，不叠加 `info`。
- 内容特征级检测仍不采纳（F01 的既有取舍，本 Feature 不改变）。

## 7. `summary` 契约

完全沿用 F01 §7：

```text
label  = 文件 basename
title  = 来源路径（与 text 中 `来源：` 行同一值）
detail = 原文块：`<行数> 行` 或 `<行数> 行（已截断）`；指针块为 `已引用过`
body   = 原文块：摘录文本（不含 `来源：` 行）；指针块：指针文案两行
```

`summary` 的任何字段都不得包含 `text` 中不存在的信息；进入消息正文、也就是发给模型的
来源路径仍只有 `text` 里的 `来源：` 行。

## 8. 已引用记录

完全沿用 F01 §8：键 `${sessionId}\u0000${workspaceRelativePath}`，容量 500，插件内存，
插件停用清空，只在 `insertQuote` 返回 `true` 后写入。接管开关的开启/关闭**不**清空或
重置记录；切换渲染实现不改变"同一文件已引用过"的事实。

## 9. 编码与失败

- 页面字节按 UTF-8 严格解码；解码失败即渲染失败，不产生摘录、不写记录、不插入。
- 桥上报的 `text` 非字符串或超过 65536 字符时整条报文被丢弃（见
  [implementation.md](implementation.md) §5.3），表现等同"当前没有可用选区"。
- 摘录必须来自当前按钮所属 tab 的 iframe（归属判定见
  [implementation.md](implementation.md) §6），不得跨 tab 借用文本。

## 10. 与格式白名单的关系

- `ALLOWED_SUFFIXES` 与 `ALLOWED_FILENAMES` 保持不变，`html` / `htm` 仍**不在**清单内，
  且不得加入。F01 的 U-10 断言原样通过。
- HTML 的可引用性由「接管生效 + HTML 适配器匹配」决定，不由白名单决定。白名单只回答
  "文本适配器是否接管该路径"，字符上永不为 HTML 回答"是"。
- 由此同样确定：文本引用按钮对 `.html` 永不渲染；HTML 的引用按钮是独立变体（见
  [implementation.md](implementation.md) §7）。

## 11. 明确不做

- 不新增 HTML 专用模板、专用截断规则或专用指针文案。
- 不把 HTML 源码作为摘录来源（渲染文本是唯一来源；要看源码请用自带的纯文本回退）。
- 不做内容特征级敏感检测、不做跨预览体选区、不做全表「会话已读」判定。
