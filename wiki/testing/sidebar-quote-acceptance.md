# 引用能力测试与验收

> 权威范围：本文件是引用能力的测试分层、必测用例、端到端环境与证据形式、验收标准的唯一
> 权威，并记录当前验收结论与残余风险。内容契约见
> [引用内容契约](../implementation/frontend/sidebar-quote-contract.md)，实现见
> [引用实现契约](../implementation/frontend/sidebar-quote-implementation.md)。

## 1. 分层与责任

| 层 | 承载 | 运行方式 | 能证明什么 |
| --- | --- | --- | --- |
| 单元层 | 模板、截断、相对化、白名单、敏感名单、已引用记录、防抖/去重、清理、适配器接缝 | 命令表 `test` | 纯逻辑正确性 |
| HTML 接管层（单元） | 接管偏好 fail-closed、闸门状态机、桥报文校验与就绪超时、按 iframe 隔离与卸载清理、`sandbox` 结构断言、字典新增键 | 命令表 `test` | 接管逻辑与状态逻辑 |
| 端到端层 | 真实侧栏里的划词 → 按钮可用性 → 插入 → 通知；接管开关、接管渲染、iframe 内拖选、闸门联动、停用清理 | 命令表 `e2e`（需外部实例与浏览器驱动） | 浏览器主链路 |
| 人工回归层 | 其他格式零影响；接管与自带渲染的可读性、可选择性、外部资源未加载 | 人眼逐项确认 + 截图 | 未破坏既有预览，接管后仍可用 |

仓库命令只覆盖逻辑部分。**任何「已验证」结论都不得只引用静态检查或单元层通过结果**；
浏览器行为必须有端到端证据。所有命令串行执行（`--test-concurrency=1`）：停用插件、切换
接管开关之类的用例会改变实例全局状态，并发会互相干扰并产生假失败。

## 2. 单元层必测用例

编号 `U-nn`，与验收标准一一对应。

| 用例 | 断言要点 |
| --- | --- |
| U-01 原文块模板 | 单行摘录 + 路径 → `摘录\n\n来源：<path>`，逐字相等 |
| U-02 保真 | 含空行、缩进、制表符、行内多空格的选区只归一化行尾，不 trim 单行、不加重排 |
| U-03 行截断 | 201 行 → 前 200 行 + 截断说明 + 空行 + 来源行 |
| U-04 字符截断 | 单行 9000 字符 → 硬截 8000 + 截断说明 |
| U-05 先到先截 | 50 行 × 400 字符 → 按字符回退到 ≤ 8000 的行边界并带说明 |
| U-06 未截断不带说明 | 10 行短文本不含截断说明，且逐字等于期望块 |
| U-07 指针块模板 | `已引用过：<path>` + 重读提示；不含摘录、不含来源行 |
| U-08 已引用记录 | 首次未命中/插入后命中；第二次为指针；不同会话独立；插入失败不写记录；容量 501 淘汰最旧 |
| U-09 路径相对化 | 工作区内相对化、大小写不同前缀仍成立、工作区外原样、根为空原样、反斜杠归一 |
| U-10 格式白名单 | 命中 md/txt/代码/数据文本与 `.env` 精确名；不命中 pdf/png/xlsx/docx/html/htm、无扩展名、空文件名；白名单常量是唯一声明点 |
| U-11 敏感名单 | 精确名、前缀族、后缀族、包含子串命中；正常文件名不命中；命中只表示需警示、不影响可引用 |
| U-12 防抖 | 350ms 内多次变化只定稿一次；超出窗口各自定稿；释放后不再定稿 |
| U-13 点击去重 | 处理中重复点击只插入一次；处理结束后可再次插入 |
| U-14 失败分支 | 无屏幕会话、无作用域、空白选区、插入被拒、归属失效、适配器抛错各一条 `error` 且零插入；无通道场景为置灰 + 竞态静默 |
| U-15 清理 | 装→卸后监听、定时器、适配器、字典、位点、订阅计数归零 |
| U-16 适配器接缝 | 重复 `id` 抛错；注销后不再被调用；假适配器无需修改核心即产出正确原文块 |
| U-17 本地化 | 中英键集合完全一致；`来源：`、截断说明、指针文案不出现在字典里 |
| U-18 `summary` 契约 | 原文块与指针块的 `label`/`title`/`detail`/`body` 符合契约；`summary` 不含 `text` 之外的信息 |
| U-19 跨预览体选区 | 锚点属 A、终点属 B 时 A 的按钮置灰且强制点击零插入、一条 `error`；同属 A 时仍可用（护栏） |

HTML 接管层的单元用例：

| 用例 | 断言要点 |
| --- | --- |
| U-20 白名单不变（护栏） | 白名单不含 `html`/`htm`（大小写均不含），精确名表仍只有 `.env`；`.html`/`.htm`/`.HTML` 均不命中；接管开关两种状态下文本适配器对 `.html` 的 `match` 恒为假 |
| U-21 两条归属分支 | 无 `witness` 时沿用三元素校验（U-19 原样通过）；有 `witness` 时 `occurrence.id` 相等才可用，不等则置灰且强制点击一条 `error`、零插入、零记录；`focusedTarget(witness)` 抛错或返回空一律置灰、异常不外泄 |
| U-22 `target` 形状 | `readSelection` 收到的 `target` 含 `path`、`document`、`anchor` 与 `tab: { sessionId, occurrenceId }`；无屏幕会话或无 occurrence 时不得臆造 `occurrenceId`，witness 分支按置灰处理 |
| U-23 报文校验 | 接受合法的 `selection` / `ready` / `error`；channel 不符、version 不符、kind 非法、`text` 非字符串、超长、`source` 不是该 iframe、`origin` 不是 `'null'`、data 为 null/数字/数组一律丢弃且不抛错；丢弃不得清除已有可用文本 |
| U-24 桥状态按 iframe 隔离 | 两个 iframe 各自上报互不串文本；同一路径两窗格各开一次互不影响；iframe 卸载删除条目；全部卸载后缓存为空 |
| U-25 就绪超时与恢复 | 4000ms 内未收到 `ready` 标记不可用；迟到的 `ready` 恢复可用且不需重挂载；`error` 后到达的 `ready` 同样恢复 |
| U-26 闸门状态机 | `persistedOn=true` + `gateOpen=false` 时零注册；闸门变真注册一次且不重复；再变假全部注销、监听移除、桥缓存清空，而 `persistedOn` 仍为真 |
| U-27 持久化 fail-closed | 键缺失、`''`、`'off'`、`'ON '`、`'1'` 均视为关闭；读取抛错视为关闭且不抛；写入抛错时视觉状态仍更新、下一次读取仍按关闭处理 |
| U-28 开/关/卸载计数 | 装→开→关→卸与装→开→卸两条路径下，定义、正文、开关、按钮、`message` 监听、桥缓存、blob URL 全部归零；卸载路径自行完成回收（`revoked === created`） |
| U-29 通知预算 | 开启自检成功恰一条 `info`、闸门不可用恰一条 `error`、桥未就绪恰一条 `info` 且同一页目标不重复；状态通知不占用点击路径预算 |
| U-30 只加不减（结构断言） | 新增项恰好为一个适配器 + 一个正文位点 + 一个引用按钮位点 + 一个开关位点；文本适配器 id、`match`、`readSelection` 与文本按钮渲染条件、白名单常量、模板与截断常量均未变 |
| U-31 字典键 | 中英新增键集合完全一致；`来源：`、截断说明、指针文案仍不在字典中 |

## 3. 端到端必测用例

编号 `E-nn`，全部在独立 profile 与独立端口上运行。

| 用例 | 内容 |
| --- | --- |
| E-01 首次引用闭环 | 打开工作区文本文件 → 划词 → 350ms 后按钮可用 → 真实鼠标点击 → 输入框出现「摘录 + 空行 + 来源：相对路径」 |
| E-02 同文件再引 | 同一文件再划另一段 → 指针块，不含原文 |
| E-03 跨文件独立 | 另一文件 → 原文块，未被前一个文件的记录影响 |
| E-04 其他格式零影响 | 先在同一页做正向对照（白名单内的文本文件确实出现按钮），再逐格式确认无按钮且预览表现与未安装插件一致；`.html` 的判据是「无文本引用按钮、有接管开关」 |
| E-05 敏感文件 | 命中敏感名单且在白名单内的文件原样插入 + 恰好一条 `info`（断言条数与 `role`），零 `error` |
| E-06 无选区 | 不划词 → 按钮置灰 |
| E-07 切 tab 后选区失效 | 划词 → 切到另一个预览 tab → 切回 → 旧选区不再可用 |
| E-08 停用清理 | 停用插件 → 按钮消失、再划词无反应、控制台无报错 |
| E-09 双窗格跨预览体 | 两个窗格各开一个文本预览 → 跨窗格选区时按钮不可用；环境不支持双窗格时记「不适用」，不得计为通过 |

HTML 接管层的端到端用例：

| 用例 | 内容 |
| --- | --- |
| E-10 关闭态正文等价 | 清空接管偏好 → 打开 HTML 夹具 → 断言头部有开关且为关、无引用按钮 → 对正文区域截图，与「插件停用阶段（整页刷新后）」的同区域截图逐字节对比 → 断言正文仍是自带实现（自带 iframe 标记存在、`sandbox` 与停用阶段相等）→ 控制台无 error |
| E-11 开启自检 | 点击开关 → 恰好一条 `info` → 正文出现接管标记 → 自带 iframe 消失 → 出现 HTML 引用按钮且置灰 → 父页面收到 `origin='null'`、来源窗口全等、`version` 匹配且至少一条 `ready` 的桥报文 |
| E-12 真实拖选引用闭环 | 在 iframe 区域真实鼠标拖选可见文字 → 按钮可用 → 真实点击 → 输入框出现「摘录 + 空行 + `来源：samples/page.html`」，卡片正文与 iframe 内实际选区逐字一致 |
| E-13 同文件再引 | 同一会话内对同一 HTML 再选另一段 → 指针块，只含路径，不含原文与 `来源：` |
| E-14 无选区 | 接管开启、页面就绪、不划词 → HTML 引用按钮存在且 `disabled` |
| E-15 CSP 页面仍可引用 | 自带 `script-src 'none'` 的页面 → 接管开启 → 拖选 → 按钮可用 → 点击插入成功（失败即产品失败，不接受降级通过） |
| E-16 闸门关闭 | 把页面脚本闸门置假 → 点击开关 → 恰好一条 `error` 说明原因 → 正文保持自带实现 → 开关禁用且写明原因 → 无接管定义注册 |
| E-17 开启后关闭 | 接管开启状态下再点开关 → 正文回到自带实现、引用按钮消失、开关为关、控制台无 error、后续划词无反应 |
| E-18 停用清理与边界事实 | 接管开启 → 停用插件 → iframe 消失、开关与引用按钮消失、再划词无反应、控制台无 error、旧 `blob:` 无元素继续引用；把「已打开预览正文为空、刷新后自带回归」记为事实而非通过条件 |

环境例外：`.env` 的浏览器用例**不适用**——Files 页不列出以 `.` 开头的隐藏项，浏览器层
无法打开该文件。该规则由 U-10（精确名命中白名单）与 U-11（敏感命中不阻断）承担，不计为
通过。

## 4. 端到端环境与证据形式

| 项 | 值 |
| --- | --- |
| DSH profile | `side-quote-verify`（由自带 web 模板新建的独立 profile） |
| 端口 | 独立端口，**不得**使用用户 live 的 `3081`。契约默认 `3181`；本机 Windows TCP 保留段包含 `3119–3218`（`netsh interface ipv4 show excludedportrange protocol=tcp` 可复现）导致不可绑定，实际改用 `34181` 并在证据中写明替换原因 |
| DSH_HOME | 临时目录，不使用用户真实 `%USERPROFILE%\.dsh` |
| 浏览器 | 外部驱动的 Chromium 系浏览器，独立 `--user-data-dir` 与 CDP 端口 |
| 视口 | `1440x900`，`deviceScaleFactor: 1` |

硬要求：全程不终止、不重启、不修改用户正在使用的实例与其 profile；实验代码只进入
`side-quote-verify`；验收结束后按记录回收。

驱动方式保持零依赖：端到端测试是普通 `node:test` 文件，通过环境变量连接已存在的外部实例，
不自带浏览器驱动、不新增 `dependencies`：

| 变量 | 含义 |
| --- | --- |
| `SIDE_QUOTE_E2E_BASE_URL` | 实例地址（含启动 token），缺省时用例 skip |
| `SIDE_QUOTE_E2E_CDP` | 浏览器 CDP 端点（`ws://…` 或 `http://host:port`） |
| `SIDE_QUOTE_E2E_EVIDENCE_DIR` | 必需：截图与 sidecar 的写入目录 |
| `SIDE_QUOTE_E2E_PROFILE` | 必需：所连实例的 profile 名，写入 sidecar 作为隔离身份 |
| `SIDE_QUOTE_E2E_ALLOW_LIVE` | 显式放行对 `3081` 运行，只在明确授权时设为 `1`；默认硬拒绝 |

证据形式：截图与断言输出写入工作区证据根下的 Feature 证据目录，文件名带用例编号；每张
截图配同名 `.json` sidecar，记录 Git revision、实例 origin 与端口、profile、视口、用例
编号与时间戳；HTML 接管用例另记接管状态、选区驱动方式（`mouse` / `synthetic-range`）与
观察到的 iframe `sandbox` 属性。启动地址里的 `?token=…` 不得进入任何证据文件。夹具一律在
运行时生成到实例工作区的临时目录，仓库内不得出现名为 `.env` 的文件。

子 frame 的选区驱动：iframe 是不透明 origin，父页面无法用脚本操作其选区，因此按下列优先级
取证——① 用 CDP `Input.dispatchMouseEvent` 在 iframe 可视区域做真实按压-移动-释放（最接近
真实用户操作）；② 退化为 `Target.setAutoAttach` 或 `Page.createIsolatedWorld` 后在子 frame
构造 `Range`。用②时证据必须写明「选区由脚本合成，非物理拖选」，不得把②记为①。iframe 内
的文字几何测量与读回选区不改变这条边界。

## 5. 验收标准

| ID | 判定条件 | 依据 |
| --- | --- | --- |
| AC-1 | 首次引用闭环通过，插入内容去前缀后逐字等于模板 | U-01、U-02、E-01 |
| AC-2 | 指针降级通过，第二次插入为指针块且不含原文 | U-07、U-08、E-02 |
| AC-3 | 已引用记录按会话隔离，跨文件互不影响 | U-08、E-03 |
| AC-4 | 来源路径为工作区相对路径，工作区外保留原样 | U-09、E-01 |
| AC-5 | 截断按 200 行 / 8000 字符先到先截，未截断不带说明 | U-03…U-06 |
| AC-6 | 敏感文件名命中时原样插入且只有一条 `info` | U-11、E-05 |
| AC-7 | 格式白名单命中/不命中如约，HTML 不出现引用按钮 | U-10、E-04 |
| AC-8 | 按钮可用性由同预览体非空白选区决定（锚点与终点同属该预览体）；防抖与点击去重如约 | U-12、U-13、U-19、E-06、E-09 |
| AC-9 | 可点击的失败分支各只发一条 `error` 且不插入；无屏幕会话/无作用域表现为置灰 + 竞态静默 | U-14 |
| AC-10 | 插件停用后监听、定时器、订阅、注册全部释放 | U-15、E-08 |
| AC-11 | 零构建与零运行时依赖：`dependencies` 为空、制品 `files` 不含测试、两条 `node --check` 通过 | 命令表 `lint` |
| AC-12 | 未触碰 live 环境：sidecar 显示独立 profile 与非 `3081` 端口 | 证据记录 |
| AC-13 | 其他格式零影响：逐格式留档 | E-04 |
| AC-14 | 中英字典键齐全；内容文案不在字典中 | U-17 |
| AC-15 | 新增格式只需新增适配器 | U-16 |
| AC-16 | `summary` 只承载展示：进入消息正文的来源路径只有 `text` 中的 `来源：` 行 | U-18、E-01 |
| AC-17 | 关闭态正文与插件停用逐字节一致（裁剪到正文区域），且正文确为自带实现 | E-10 |
| AC-18 | 接管默认关闭；持久化缺失/非法/不可写一律 fail-closed 且不抛错 | U-27、E-10 |
| AC-19 | 接管开启闭环：自检一条通知 → 正文接管 → 真实拖选 → 按钮可用 → 点击插入原文块 | E-11、E-12、U-29 |
| AC-20 | 同一会话同一路径第二次为指针块，不含原文与来源行 | E-13 |
| AC-21 | 来源路径为工作区相对路径（工作区外保留原样），HTML 与文本一致 | E-12、U-09 |
| AC-22 | 归属两条分支都成立：无 witness 走三元素校验、有 witness 走 occurrence 相等；失败各一条 `error` 且不插入 | U-21、U-22 |
| AC-23 | 白名单常量与文本引用路径不变，新增项恰好为一个适配器 + 一个正文 + 一个引用按钮 + 一个开关 | U-20、U-30 |
| AC-24 | 桥报文校验按白名单执行，非法/超长/来源不符一律静默丢弃且不清空可用文本；状态按 iframe 隔离；父侧观察到 `origin='null'` 与来源全等 | U-23、U-24、E-11 |
| AC-25 | 闸门状态机正确：闸门假/未知不接管，变真自动接管，变假回落；CSP 页面仍可引用；桥未就绪可判定 | U-25、U-26、E-15、E-16 |
| AC-26 | 通知预算：开启自检各分支恰好一条，状态通知按页目标去重，不占用点击路径预算 | U-29、E-11、E-16 |
| AC-27 | 清理与可逆：开→关、开→卸、装→卸后所有注册、监听、缓存、blob 归零；关闭后正文回到自带 | U-24、U-26、U-28、E-17、E-18 |
| AC-28 | 未触碰 live 环境：sidecar 显示独立 profile 与非 `3081` 端口 | 证据记录 |
| AC-29 | 内容契约沿用：模板、截断、指针、敏感名、`summary` 与文本路径一致；HTML 摘录为渲染文本 | E-12、E-13、U-01…U-11 |
| AC-30 | 中英字典新增键齐全且一致，内容文案不在字典中 | U-31 |

AC-7 的 `.html` 判据在引入接管后被显式改写为「接管关闭时无引用按钮、有接管开关」；其余
格式的判据不变。这是唯一被改写的历史验收口径，改写理由与证据在对应过程记录中保留。

## 6. 未执行即不得声称通过

- 端到端因缺少外部驱动而 `skip` → 记「未执行」，相关 AC 不得判通过。
- 人工回归未逐格式留档 → 其他格式零影响的结论不得判通过。
- 只跑静态检查或单元层 → 不足以支撑任何浏览器行为结论。
- 选区若由脚本合成 Range 而非物理拖选，证据必须写明驱动方式，不得把合成选区记为物理拖选。

## 8. 残余风险与限制

1. **逐字链的分层**：浏览器层证明的是输入框对 `summary` 的展示与插入闭环；`text` 的逐字
   模板由单元层证明。测试刻意不发送消息，因此「发送后模型收到的正文」不在端到端范围内。
2. **选区可达性**：文本用例的选区由 DOM Range 合成、按钮点击是真实指针手势；HTML 拖选
   用例使用真实鼠标拖选并记录驱动方式。跨窗格等边缘场景仍以合成选区取证。
3. **错误级通知的可观测性**：平台错误提示的 ARIA 角色未确证，绑定断言是 `info` 的
   `role="status"` 与「零条 `error` 文案」。
4. **`.env` 浏览器用例不适用**：Files 页隐藏点开头条目，仅由单元层覆盖。
5. **格式回归的帧级等价**：逐字节相同的截图证明该视口、该时刻渲染一致；悬停与交互态、
   其他视口与缩放未纳入。
6. **桥的信任边界**：页面脚本与桥同 realm，可以伪造选区上报且无令牌；页面拿不到任何宿主
   能力，插入仍需用户点击。该边界是已接受风险，不是可验证的安全属性。
7. **接管停用后的空白期**：接管开启时停用插件，已打开的预览正文为空，需整页刷新才回归
   自带渲染；属平台侧行为，已作为已知边界记录。
8. **非焦点用法依赖**：`focusedTarget(iframe)` 的用法属「实现能力 > 文档承诺」，平台收紧时
   表现为按钮置灰而非插错文件。
9. **平台耦合**：手写 bundle 与 DSH `0.2.2-rc.3` 客户端接口强耦合，升级到新版本后必须
   重跑单元层与端到端层，责任在本项目。
