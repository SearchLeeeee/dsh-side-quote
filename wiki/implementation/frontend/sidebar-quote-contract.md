# 引用内容契约

> 权威范围：本文件是进入会话输入框的引用文本、来源路径、截断、敏感规则、格式白名单与
> 已引用记录的唯一权威。实现流程见[引用实现契约](sidebar-quote-implementation.md)，验收
> 见[测试与验收](../../testing/sidebar-quote-acceptance.md)。

## 0. 为什么内容写进 `text` 而不是 `summary`

`insertQuote(text, summary)` 的两个参数去向不同：

- `text` 成为编辑器里引用节点的内容，`getTextContent()` 返回按行加 Markdown 引用前缀后的
  文本，**随消息发送给模型**；
- `summary` 只在输入框内作为可读展示，不进入消息正文。

因此来源路径必须写在 `text` 里；`summary` 只承担人看的摘要。

## 1. 原文块模板

以下是**传给 `insertQuote` 的 `text` 原始文本**（尚未加 `> ` 前缀）：

```text
<摘录第 1 行>
<摘录第 2 行>
…
<空行>
来源：<来源路径>
```

约束：

- 摘录保真：原样保留空行、缩进、制表符与行内空白，不重排、不 trim 单行、不加代码围栏。
- 整段首尾各去掉一个空行（选区首尾的空白行不进入引用）。
- 摘录为空或仅空白时不插入，走失败路径。
- 行尾统一归一为 `\n`。
- `来源：` 行与摘录之间**恰好一个空行**。
- `来源：` 是固定中文标签，不随界面语言变化：它是进入消息正文的内容标识，不是 UI 文案。

断言方式：把插入后的消息文本按行去掉前导 `> `（允许其后的一个空格），再与期望原始文本
逐行逐字比对。

## 2. 指针块模板

同一会话内同一路径自第二次引用起，用指针块替代原文块：

```text
已引用过：<来源路径>
原文未重复贴出；需要时请重新读取该文件。
```

约束：

- 只给路径，不含行号、不含摘录锚点、不含摘录片段。
- 不含 `来源：` 行（路径已在首行给出）。
- 与原文块互斥：一次插入只会是其中一种形态。
- 指针块本身也写入已引用记录，保持记录幂等。

## 3. 格式白名单

白名单是**唯一声明点**：`code/client.js` 顶部的两个常量
`ALLOWED_SUFFIXES`（后缀集合）与 `ALLOWED_FILENAMES`（精确文件名集合）。文档不重复
罗列清单，只说明判定规则；清单以代码为准。

规则：

- 匹配对象是**文件名**（最后一段路径），大小写不敏感。
- 后缀匹配：文件名以 `.` + 后缀结尾即命中（复合后缀不入本版）。
- 精确文件名匹配：与 `ALLOWED_FILENAMES` 完全相等（大小写不敏感）。
- 无扩展名且不在精确名表中则不命中。
- `html` / `htm` **不在**白名单内，且不得加入：打开 HTML 预览时文本引用按钮不出现。
- `ALLOWED_FILENAMES` 的存在理由是 `.env` 这类没有可匹配后缀、但需求要求仍可引用的
  文件；缺少这一维度会让「敏感文件仍可引用」的验收用例不可达。

## 4. 截断规则

阈值：**200 行 / 8000 字符，先到先截**。两个阈值是 `code/client.js` 顶部常量，单一声明点。

算法（顺序固定）：

1. 归一化行尾为 `\n`，去掉首尾各一个空行。
2. 按 `\n` 切分为行。
3. 若行数 > 200：保留前 200 行，标记「已截断」。
4. 拼接保留行；若拼接结果长度 > 8000：从末尾逐行回退，直到长度 ≤ 8000，标记「已截断」；
   若即使第一行也超长，则对第一行硬截到 8000 字符。
5. 已截断时，在摘录最后一行之后插入一行固定说明：
   `…（摘录已截断，仅保留前 200 行 / 8000 字符）`。
6. 再拼接空行与 `来源：<path>`。

约束：

- 截断说明只在确实截断时出现，绝不出现「未截断却提示」。
- 截断说明是固定文案，不随语言变化（同 `来源：` 的理由）。
- 截断只发生在行边界，唯一例外是「第一行本身超长」的硬截。

## 5. 来源路径

### 5.1 形式

- 工作区内的文件：**工作区相对路径**，`/` 分隔，不带前导 `./` 或 `/`。
- 工作区外的文件：保留原样（绝对路径或原地址），只做分隔符归一。
- Windows 反斜杠一律归一为 `/`。

### 5.2 相对化算法

```text
输入：absolutePath（预览业主提供的原始路径）、workspaceRoot（会话工作区根，可能为空）
1. 两者都做：反斜杠 → '/'，去掉末尾多余 '/'。
2. workspaceRoot 为空 → 返回归一化后的 absolutePath。
3. 大小写不敏感地比较 absolutePath 是否以 workspaceRoot + '/' 开头：
   - 是 → 返回去掉前缀后的剩余部分（保留原始大小写）。
   - 否 → 返回归一化后的 absolutePath。
4. 剩余部分为空（目标就是工作区根） → 返回归一化后的 absolutePath。
```

- Windows 路径大小写不敏感，因此前缀比较必须忽略大小写；输出保留原始大小写。
- 不做符号链接解析、不做 `..` 折叠；路径已由宿主解析过。
- 相对化失败不是错误：保留原样继续，不通知、不阻断。

## 6. 敏感文件警示

### 6.1 名单

单一声明点：`code/client.js` 顶部常量 `SENSITIVE_NAME_PATTERNS` 的三段（精确名集合 +
后缀集合 + 包含子串集合）。匹配对象为文件名，大小写不敏感。覆盖形态包括精确名 `.env`、
前缀族 `.env.local` 一类、后缀族 `*.pem` / `*.key` / `*.pfx` / `*.p12` / `*.jks`，以及
名称包含 `id_rsa`、`id_ed25519`、`credential`、`secret`、`password`、`passwd`、`keystore`
的文件。

### 6.2 行为

- 命中**不阻断**：照常生成原文块或指针块并插入。
- 命中且插入成功 → 恰好一条 `info` 通知，文案形如
  `已引用可能含敏感内容的文件：<path>。内容已原样插入，请确认是否要发送。`
- 命中且插入失败 → 只发失败的那条 `error`，不叠加 `info`。
- 未命中 → 不发任何通知。

### 6.3 已知取舍

不做内容特征级检测（不识别 `sk-…`、`AKIA…`、`BEGIN PRIVATE KEY` 等样式）。普通文本里
抄写的密钥不会被警示。该取舍写入 `code/README.md`。

## 7. `summary` 契约

```text
label  = 文件 basename
title  = 来源路径（与 text 中 `来源：` 行同一值）
detail = 原文块：`<行数> 行` 或 `<行数> 行（已截断）`；指针块为 `已引用过`
body   = 原文块：摘录文本（与 text 中摘录部分一致，不含 `来源：` 行）
         指针块：指针文案两行
```

约束：

- `summary` 的任何字段都不得包含 `text` 中不存在的信息；它只是展示副本。
- `title` 是**展示副本**：进入消息正文、也就是发给模型的来源路径只有 `text` 里的
  `来源：` 行；`summary` 不随消息发送。

## 8. 已引用记录

```text
键：`${sessionId}\u0000${workspaceRelativePath}`
值：{ firstQuotedAt: number }
容量：最近 500 条，超出按插入顺序淘汰
生命周期：插件内存；插件停用清空；不持久化
写入时机：insertQuote 返回 true 之后
```

- 键使用**插入时**写入 `text` 的那个路径字符串，保证读写成对一致。
- 不同会话隔离；同一会话内跨预览关闭重开仍生效。
- 指针块也写记录（幂等，不改变首次引用时间）。
- 插入失败不得污染记录。

## 9. 与格式无关的稳定性

内容契约对所有被引用格式一致：模板、截断、路径、敏感名、`summary` 与记录结构不因格式
不同而分叉。新增可引用格式只允许新增适配器，不得引入格式专用的模板、截断或指针文案。
